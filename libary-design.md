# Design "Libary system"

## Product

### Resources

- product
- product_name
- product_category
- product_price

### Method & Status

| Method | URI             | คำอธิบาย                           | status           | ใช่เมื่อ                                                                                  |
| ------ | --------------- | ---------------------------------- | ---------------- | ----------------------------------------------------------------------------------------- |
| GET    | `/product`      | ดูหนังสือทัั้งหมด                  | 200              | ดึงรายการหนังสือสำเร็จ                                                                    |
| GET    | `/product/{id}` | ดูหนังสือแค่เล่มเดียว              | 200              | เจอหนังสือ                                                                                |
|        |                 |                                    | 404(not found)   | "ไม่พบหนังสือเล่มนี้"                                                                     |
| POST   | `/product/{id}` | เพิ่มหนังสือ                       | 201(Created)     | "เพิ่มหนังสือสำเร็จ"                                                                      |
|        |                 |                                    | 400(bad request) | "กรุณากรอกข้อมูลให้ครบ"                                                                   |
|        |                 |                                    | 409(conflict)    | "มีหนังสือที่ชื่อซ้ำกันหรือมีข้อมูลซ้ำกัน"                                                |
| PUT    | `/product/{id}` | แก้ไขข้อมูลทั้งหมดหนังสือเล่มเดียว | 200              | "แก้ไขข้อมูลหนังสือสำเร็จ"                                                                |
|        |                 |                                    | 400(bad request) | ราคา:"กรุณาใส่ตัวเลข", ชื่อ:"กรุณาใส่ชือหนังสือ", ใส้ข้อมูลไม่ครบ:"กรุณากรอกข้อมูลให้ครบ" |
|        |                 |                                    | 404(not found)   | ไม่พบหนังสือเล่มนี้                                                                       |
| DELETE | `/product/{id}` | ลบข้อมูลหนังสือเล่มเดียว           | 204 (No)         | ลบข้อมูลหนังสือสำเร็จ                                                                     |
|        |                 |                                    | 409 (Conflict)   | "ไม่สามารถลบข้อมูลได้เนื่องหนังสือเล่มนี้ถูกยืมอยู่"                                      |
|        |                 |                                    | 404(not found)   | ไม่พบหนังสือเล่มนี้                                                                       |

### JSON

`/product/{id}
{
"product_name": "ชื่อหนังสือ",
"product_category": {หมวดหมู่1,หมวดหมู่2,หมวดหมู่3,..}",
"product_price": "ราคา",
"product_number": จำณวนหนังสือทั้งหมด,
"product_use_number": จำณวนผู้ยืมทั้งหมด
}`

## Category

### Resources

- category

### Method & Status

| Method | URI              | คำอธิบาย                   | status         | ใช่เมื่อ                                          |
| ------ | ---------------- | -------------------------- | -------------- | ------------------------------------------------- |
| GET    | `/category`      | ดูหนังสสือทุกหมวดหมู่      | 200            | ดึงข้อมูลหนังสือทุกหมวดหมู่สำเร็จ                 |
| GET    | `/category/{id}` | ดูหนังสือหมวดหมู่เดียว     | 200            | ดึงข้อมูลหนังสือเฉพาะหมวดหมู่ที่กำหนดสำเร็จ       |
|        |                  |                            | 404(not found) | "ไม่พบหมวดหมู่นี้"                                |
| POST   | `/category/{id}` | เพิ่มหมวดหมู่หนังสือ       | 201            | เพิ่มหมวดหมู่สำเร็จ                               |
|        |                  |                            | 409(Conflict)  | "ชื่อหมวดหมู่นี้ถูกใช้แล้วกรุณาเพิ่มเป็นชื่ออื่น" |
| PUT    | `/category/{id}` | แก้ไขข้อมูลหมวดหมู่หนังสือ | 200            | แก้ไขชื่อหมวดหมู่สำเร็จ                           |
|        |                  |                            | 409(not found) | "ชื่อหมวดหมู่นี้ถูกใช้แล้วกรุณาแก้ไขเป็นชื่ออื่น" |
| DELETE | `/category/{id}` | ลบชื่อหมวดหมู่หนังสือ      | 204            | "ลบหมวดหมู่สำเร็จ"                                |
|        |                  |                            | 404(not found) | "ไม่มีชื่อ category นี้"                          |

### JSON

`/category/{id}
{
[
"product_name": "ชื่อหนังสือ",
"product_number": จำณวนหนังสือทั้งหมด,
"product_use_number": จำณวนผู้ยืมทั้งหมด,
"product_category": {หมวดหมู่1,หมวดหมู่2,หมวดหมู่3,..}"
],
...

}`

## Orders

### Resources

- customer
- customer_name
- orders

### Method

| Method | URI                                | คำอธิบาย                         | status         | ใช่เมื่อ                                                                     |
| ------ | ---------------------------------- | -------------------------------- | -------------- | ---------------------------------------------------------------------------- |
| GET    | `/customers/{date}/orders`         | ดูประวัติคำสั่งยืม ณ วันที่นั้นๆ | 200            | แสดงประวัติการสั่งยืม ณ วันที่นั้นๆ                                          |
| GET    | `/customers/{profuct_name}/orders` | ดูประวัติคำสั่งยืมจากชื่อหนังสือ | 200            | แสดงประวัติการสั่งยืมหนังสือชื่อ                                             |
| GET    | `/customers/{id}/orders`           | ดูประวัติคำสั่งยืม               | 200            | แสดงประวัติการสั่งยืม                                                        |
|        |                                    |                                  | 409(Conflict)  | "กรุณาใสข้อมูลเป็นรหัส order หรือ วันที่ หรือชือหนังสือ"                     |
|        |                                    |                                  | 404(not found) | "ไม่พบประวัติการยืมนี้"                                                      |
| POST   | `/customers/{id}/orders`           | สั่งยืม (checkout)               | 200            | ""                                                                           |
|        |                                    |                                  | 409(Conflict)  | "กรุณากรอกข้อมูลให้ครบ", "หนังสือเรื่องนี้ถูกยืมจนคครบจำนวนกรุณายืมเล่มอื่น" |
|        |                                    |                                  | 404(not found) | "ไม่พบหนังสือที่คุณต้องการยืมอยู่ในระบบ"                                     |
| GET    | `/orders/`                         | ดูคำสั่งยืมทั้งหมด               | 200            | แสดงการยืมทั้งหมด                                                            |
|        |                                    |                                  | 404            | "ยังไม่มีการยืมในระบบ"                                                       |
| GET    | `/orders/{id}`                     | ดูคำสั่งยืมเดียว                 | 200            | แสดง order id                                                                |
|        |                                    |                                  | 404            | "ไม่พบการยืม order id ในระบบ"                                                |
| PUT    | `/orders/{id}`                     | อัปเดตสถานะ (เช่นยกเลิก)         | 201            | "สถานะมีการ update"                                                          |
|        |                                    |                                  | 409(conflict)  | "order id ถูกใช้แล้ว"                                                        |

### JSON

- customers
  `/customers/{id}/orders
  {
  "customers_id": "id ผู้ยืม",
  "customers_status": "สถานะการยืม", <!-- (เช่น ยืม, คืน และ เกินกำหนดยืม เป็นนต้น) -->

"product_id": รหัสหนังสือ,
"product_price": ราคาหนังสือ,

"date_borrow": "วันที่ยืม",
"date_due": "วันทีกำหนดคืน",
"date_return": "วันที่คืน",
"date_ext": จำนวนวันที่เกินกำหนดคืน

}`
